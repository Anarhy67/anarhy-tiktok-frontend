# ANARHY — запуск вручную через Telegram

## Что работает в MVP
- Главная страница и кабинет.
- Задания TikTok.
- Отчёты со ссылкой и подтверждением.
- Раздел ANARHY Partners отдельно от TikTok.
- Ручная оплата через личку администратора Telegram.
- Ручные выплаты через личку администратора Telegram.
- Ручное добавление и публикация отзывов.

## Что пока НЕ подключаем
- Платёжные шлюзы.
- Автоматические выплаты.
- Telegram-бота.
- Автоматические вебхуки оплаты.

## Перед первым запуском
1. Вставить username администратора Telegram в кнопки связи.
2. Заменить демо-тексты и демо-цифры.
3. Добавить первый оффер.
4. Добавить реальные правила и условия.
5. Добавить только настоящие отзывы с разрешения авторов.
6. Проверить сайт на телефоне.
7. Создать резервную таблицу ручных оплат и выплат.

## Формат ручного учёта
- Дата
- Telegram username / ID
- Имя клиента
- Оффер
- Сумма
- Статус: ожидает / оплачено / отменено
- Партнёрский код
- Комиссия
- Статус выплаты
- Комментарий администратора
